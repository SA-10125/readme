# readme

Worked on ShatterLock which is a local encryption system that I will one day extend to beyond local. It encrypts files with multiple algorithms, then shatters the files into many pieces and stores all the pieces in different subfolders of the system. It includes junk packets and its encrypted in such a way that each piece depends on the other. The point is that an attacker who has acess to the system cant just copy the file onto a pendrive then go home and brute force attack the password. Cause the file itself cant be found.
